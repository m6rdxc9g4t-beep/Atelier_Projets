# Icônes simplifiées des apps atelier_

Version « favicon » des logos, demandée par la charte néon holographique 3D (point « lisibilité en petit ») :
carré arrondi en verre bleu nuit ; bord chromé, halo et pictogramme néon dans la **couleur signature** de l'app.

| App | Fichier | Signature | Pictogramme |
|---|---|---|---|
| atelier_Ciné | `cine.svg` | `#E64980` | lecture |
| atelier_Viz | `viz.svg` | `#F2C811` | histogramme |
| atelier_Tab | `tab.svg` | `#21A366` | tableau |
| atelier_Savoir | `savoir.svg` | `#9B5DE5` | toque |
| atelier_Trésorerie | `tresorerie.svg` | `#3B5BDB` | banque |
| atelier_Projets | `projets.svg` | `#94D82D` | calendrier coché |
| atelier_Dates | `dates.svg` | `#E03131` | cœur dans deux cercles |
| atelier_Nexus | `nexus.svg` | `#E8590C` | N en réseau |

Ces SVG sont les sources ; chaque app embarque les rendus PNG : `favicon-64.png` (transparent) et
`apple-touch-icon.png` (180 px, opaque, plein cadre). Pictogrammes : Lucide (licence ISC), sauf Dates et Nexus.
